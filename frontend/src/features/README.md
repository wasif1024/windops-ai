# Features

One folder per SRS 4.11 area, as each is built: `admin/` is the administrator console, `platform/` the Platform
console, `fleet/` the fleet overview, turbine detail and telemetry charts, `alarms/` the alarm console, each alarm's
history and what operators do to it, and so on. See
[the frontend README](../../README.md#structure) for what goes inside one.
